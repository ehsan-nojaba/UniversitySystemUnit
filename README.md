# سامانه پیش‌انتخاب واحد دانشگاه

این پروژه نیاز درسی دانشجویان و آمادگی تدریس استادها را برای یک ترم جمع می‌کند تا کارشناس آموزش درباره ارائه درس، استاد و زمان کلاس تصمیم بگیرد. سپس دانشجو نتیجه را می‌بیند و می‌تواند ثبت‌نام قطعی انجام دهد.

سه فرایند اصلی پروژه، فرایند **دانشجو، استاد و آموزش** هستند؛ همه در یک سامانه قرار دارند.

برای مطالعه و ارائه، از [راهنمای فارسی پروژه](docs/PROJECT_GUIDE.fa.md) شروع کنید. برای پیدا کردن مسئولیت هر کلاس، [نقشه فایل‌ها و مدل‌ها](docs/CODE_MAP.fa.md) را ببینید. تغییرات این مرحله در [گزارش تمیزکاری](docs/CLEANUP.fa.md) آمده‌اند.

## ساختار

- `src/UniversitySystem.Domain`: مدل‌ها و قواعد داخلی آن‌ها.
- `src/UniversitySystem.Application`: عملیات آموزشی، اعتبارسنجی، قراردادها و هماهنگی سرویس‌ها.
- `src/UniversitySystem.Persistence`: EF، ریپازیتوری‌ها و نگاشت جدول‌ها.
- `src/UniversitySystem.Infrastructure`: JWT، هش رمز، اطلاعات کاربر جاری و زمان.
- `src/UniversitySystem.Api`: مسیرهای HTTP و اتصال سرویس‌ها.
- `tests`: تست واحد و تست یکپارچه با دیتابیس موقت مستقل.

## اجرا و بررسی کد

پیش‌نیاز: SDK دات‌نت ۱۰ و وابستگی‌های NuGet پروژه.

```powershell
dotnet restore
dotnet build
dotnet run --project src/UniversitySystem.Api
```

Swagger در محیط Development در مسیر `/swagger` و سلامت API در `/health` قرار دارد. تنظیم اتصال موجود پروژه در این مرحله تغییر نکرده است. برنامه در زمان شروع میگریشن خودکار اجرا نمی‌کند.

## وضعیت این مرحله

تمیزکاری، APIهای لازم UI و بررسی سناریوی اصلی دانشجو، استاد و آموزش تکمیل شده‌اند. مسیر اصلی تا ثبت‌نام قطعی و گزارش با دیتابیس موقت تست شده است. آزمون هم‌زمانی روی SQL Server و دمو با داده واقعی مراحل جداگانه‌اند. وجود مدل نمره، لغو یا اطلاعات پایه به معنی وجود API کامل آن‌ها نیست؛ جزئیات در راهنما آمده است.

برای شروع فرانت‌اند، [قرارداد فارسی UI و نمونه درخواست‌ها](docs/UI_API.fa.md) را بخوانید. API فهرست ترم، درس فعال، استاد و حساب جاری در Feature `UiSupport` قرار دارد.
